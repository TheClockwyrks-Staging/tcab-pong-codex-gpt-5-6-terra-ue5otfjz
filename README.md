# Carom

Carom is a fast top-down paddle duel. Move your paddle as you strike to load the ball with spin, curve it around the amber blockers, and outplay your opponent in a rally of bank shots.

## Run it

Install dependencies with `npm ci`, then use `npm run dev` for a local development server. Build the self-contained static site with `npm run build`; its output is in `dist/`.

## Controls

- Player one: `W` / `S`
- Player two: `↑` / `↓` (or play Solo against the AI)
- Select: `Enter` or `Space`
- Pause: `P` or `Escape`
- Mute: `M`

First to 11 points, winning by two, takes the match.
